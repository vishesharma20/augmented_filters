One setup step needed: this app was opened directly as a file, and browsers block local pages from loading local AI model files that way. In VS Code, right click index.html in the file explorer and choose Open with Live Server (install the free Live Server extension first if you do not have it), then use the address it opens instead of opening the file directly. You can also run python -m http.server in this folder and visit the address it prints.
